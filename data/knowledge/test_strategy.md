# Test strategy learning guide

A test strategy fixes the levels, the entry and exit criteria, and the risk ranking before execution starts, so later choices are already decided. Rank features by the damage a failure would cause and spend the deepest testing on the highest ranks. Name the environment and the data a level needs, because a missing environment is the usual reason a plan fails.

Practice: rank the features of one release by failure impact, set entry and exit criteria for each level, and record which risks your plan does not cover.
